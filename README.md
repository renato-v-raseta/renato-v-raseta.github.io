# renato-v-raseta.github.io

The source of my CV landing page, published at **[renato-v-raseta.github.io](https://renato-v-raseta.github.io)**.

## What is in here

| File | What it is |
|---|---|
| `index.html` | The page itself, including all of its text |
| `styles.css` | How the page looks |
| `photo.jpg` | The profile photo, once it is added |

No build step, no framework, no dependencies. GitHub publishes these files exactly as they are.

## How to change something

Edit `index.html` for words, `styles.css` for looks, then save and push. GitHub republishes the page within a minute or two. A browser sometimes keeps showing the old version, so force refresh if a change does not appear.

## What must never go in here

This repository is public, and its history is public too. Deleting a file does not remove it from the history.

- No email address, no phone number, no home address
- No client names
- Nothing from the vault
- No credentials of any kind

Facts on this page also live in `40-49 Work/44 Career/Job Search 2026/Profile.md`, which is the canonical source. If a fact changes, change it there as well.
